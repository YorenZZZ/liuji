# 留迹 1.1.0 首次开源发布

## 用户目标
提供可 Docker 自托管的纯文字创作、图片导出与多平台发布记录工具，并公开源码与镜像。

## 沟通结论
保持单一暖白纸面风格；发布登记只记录用户已经完成的发帖。开源版默认登录，首次设置密码，登录后改密无需旧密码，支持退出；可信内网可显式关闭网页登录。

## 实施记录
实现 SQLite 原稿与发布快照、版本冲突保护、回收站、在线备份、MCP 只读和读写权限、PNG 长文分页及 Docker Compose。改密使其他设备会话失效。版本 1.1.0 新增首次设密与账户管理流程。

## 验证结果
12 项隔离测试、JavaScript 语法、生产构建和公开文件检查通过。此前桌面与窄屏保存、发布登记及 PNG 导出已实测。镜像双架构发布由 GitHub Actions 执行，结果以工作流状态为准；手机真机分享尚未验证。

## 教程提炼
原稿和发布快照分离；客户端保留失败编辑区，服务端以版本号拒绝覆盖。MCP 使用独立权限令牌，凭据与内容不进入源码。

## 隐私检查
公开目录仅含通用源码、测试、部署模板及本文，无运行数据库、个人笔记、访问令牌、私有主机地址或本机路径。
